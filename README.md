# 끄투 LITE (KKuTu-Lite)

초경량 한국어 실시간 끝말잇기 웹 게임 (Vercel 배포용)

## ✨ 특징
- **국립국어원 표준국어대사전 332,231단어 탑재**: 모든 일반 한국어 명사 및 쿵쿵따 어휘 지원
- **어인정 모드 (Injeong Mode)**: 게임, 애니, 롤, 포켓몬, 대중문화, 밈 단어 허용 및 커스텀 단어 등록
- **정통 끄투 룰셋**: 라운드 제시어 글자판, 두음법칙 자동 적용, 매너모드, 한방단어 방지 룰, 미션 글자 보너스
- **6가지 감성 테마**: 오리지널 끄투(칠판/우드), 파스텔 캔디, 말차 포레스트, 선셋 라운지, 아케이드 네온, 모던 미니멀
- **P2P WebRTC 1-클릭 멀티플레이**: Vercel 배포 후 방을 만들고 [🔗 링크 복사]를 눌러 친구에게 링크를 보내면 클릭 한 번으로 자동 접속
- **단어 입력창 & 채팅창 완전 분리**: 중앙 전광판 내부에 전용 단어 입력창 배치

## 🚀 Vercel 배포
Vercel에 본 저장소를 Import하면 별도의 빌드 과정 없이 즉시 배포됩니다.
