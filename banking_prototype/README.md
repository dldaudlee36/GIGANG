# OK저축은행 모바일 프로토타입 (PWA)

아이폰(iOS Safari) 환경에서 네이티브 은행 앱과 동일한 화면과 사용성을 테스트할 수 있는 웹 기반 프로토타입입니다.

---

## 📱 아이폰에서 테스트하는 방법

### 1. 로컬 Wi-Fi로 내 아이폰에서 바로 열기
컴퓨터와 아이폰이 **같은 Wi-Fi 공유기**에 연결되어 있다면 바로 접속할 수 있습니다.

1. **로컬 웹서버 실행** (터미널에서 실행):
   ```bash
   python -m http.server 8080 --directory banking_prototype
   ```
2. **컴퓨터 IP 확인**:
   * Windows: 터미널에서 `ipconfig` 실행 후 `IPv4 주소` 확인 (예: `192.168.0.15`)
3. **아이폰 Safari 브라우저에서 접속**:
   * 주소창에 `http://[내_컴퓨터_IP]:8080` 입력 (예: `http://192.168.0.15:8080`)

---

### 2. 아이폰 "홈 화면에 추가" (네이티브 앱 모드)
Safari에서 브라우저 주소창과 네비게이션 바를 완전히 없애고 실제 은행 앱처럼 띄우는 방법입니다:

1. Safari 하단 중앙의 **[공유] 아이콘(네모 위로 화살표)** 터치
2. 메뉴에서 **[홈 화면에 추가]** 선택
3. 이름을 확인하고 우측 상단 **[추가]** 터치
4. 아이폰 바탕화면에 생성된 **OK저축은행 아이콘**을 터치하여 실행

---

## ⚙️ 탑재된 인터랙션 기능
- **가상 송금**: '송금하기' 터치 시 iOS 바텀시트가 열리며, 가상 송금 시 상단 잔액(18,109,423원)에서 실제 차감 반영
- **출석체크**: '출석하기' 터치 시 '출석완료'로 변경 및 +10P 적립
- **룰렛 돌리기**: 룰렛 배너 터치 시 회전 애니메이션과 함께 보너스 포인트 당첨 팝업
- **하단 5개 탭**: 홈 / 혜택 / 마이 / 자산관리 / 전체 전환 반응
- **초기화 기능**: 상단 `OK! 저축은행` 로고를 터치하면 원래 초기 잔액 및 상태로 리셋 가능
