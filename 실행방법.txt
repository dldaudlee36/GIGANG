GIGANG 3.6.4 — 실행 3개 + 종료 3개 정리본

세 개 중 필요한 것 하나만 실행하세요.

start-all.bat  : 전체 실행. Agent + 관리자 대시보드. 한 PC에서 시연할 때.
ADMIN_START.bat: 관리자 실행. 대시보드만. Windows 관리자 권한 불필요.
USER_START.bat : 이용자 실행. Agent만. 사용자 PC에서 실행.

전체/이용자 실행 시 Windows 관리자 권한 요청을 허용하세요.
Windows 권한과 프로젝트의 관리자/이용자 역할은 별개입니다.
전체 실행 후 관리자/이용자 실행을 추가로 누르지 않아도 됩니다.
이미 포트를 사용하는 프로그램이 있으면 해당 구성요소 실행을 건너뜁니다.
이전 버전은 실행 중인 Agent/대시보드 창을 먼저 종료하고 새 버전을 실행하세요.

처음 준비
1. ZIP 전체를 새 폴더에 압축 해제하세요. BAT만 따로 옮기지 마세요.
2. Python 3가 필요합니다. 필요한 패키지는 첫 실행 시 설치합니다.
3. 이용자 또는 전체 시연 PC에서는 chrome://extensions 에서 기존 확장을 제거하고,
   개발자 모드 -> 압축해제된 확장 프로그램 로드 -> app_files/browser_extension 을 선택하세요.
4. DB와 외부 사이트 탭을 새로고침하세요.
5. 관리자 대시보드에서 이벤트 수집을 ON으로 켜세요.

프로그램을 사용하는 동안 Agent/대시보드 실행 창을 켜두세요.
종료할 때는 아래 파일을 사용하세요.
stop-all.bat  : 전체 종료. Agent + 대시보드 종료, 이 PC의 GIGANG hosts 차단 해제.
ADMIN_STOP.bat: 관리자 종료. 대시보드만 종료. Agent와 차단은 유지.
USER_STOP.bat : 이용자 종료. Agent 종료, 이 PC의 GIGANG hosts 차단 해제.

종료 파일 실행 시 Windows 관리자 권한 요청을 허용하세요.
관리자 권한으로 켜진 대시보드도 종료할 수 있도록 종료 파일은 권한을 요청합니다.
이 패키지 경로에서 실행된 프로세스만 종료합니다. 다른 폴더의 이전 버전은 그쪽에서 종료하세요.
크롬 탭과 확장은 자동으로 닫거나 삭제하지 않습니다.
종료 후 감지 기록을 정상 전송하려면 Agent를 다시 실행해야 합니다.
중앙 서버의 차단 정책은 삭제하지 않으므로 Agent 재실행 시 정책이 다시 적용됩니다.
다른 hosts 항목은 유지하고 GIGANG 표식 안의 항목만 제거합니다.
변경 전 hosts 사본은 app_files/launcher-logs/hosts-before-stop.bin에 저장됩니다.

프로그램과 기존 설정은 app_files 안에 있습니다.
복사/붙여넣기 및 다운로드/업로드 연결 기능은 기존 3.6.0과 동일합니다.
상세 기능: app_files/내용일치_사용법.txt
기존 연결 설정이 포함되어 있으므로 ZIP 전체를 공개 저장소에 올리지 마세요.

3.6.1 수정
HIGH 상태에서 낮은 위험 이벤트가 들어와도 상태·점수·근거·만료 시각을 유지합니다.
기존 TTL 만료와 명시적 초기화는 유지합니다. 수집은 대시보드에서 ON으로 켜세요.
이미 잘못 내려간 기존 상태를 강제로 올리지는 않습니다. 새 내용 일치 이벤트부터 확인하세요.
브라우저 감지 코드는 3.6.0 그대로입니다.

3.6.2 차단 안내창 연결
새 확장 app_files/browser_extension을 재등록하고 DB/외부 사이트 탭을 새로고침하세요.
1. 사내 자료 내용 일치 감지 시 해당 외부 사이트 탭을 보안 안내 화면으로 전환합니다.
2. 관리자 차단 목록에 있는 사이트에 접속하면 정책 안내 화면으로 전환합니다.
3. HIGH라는 이유만으로 모든 사이트를 차단하지는 않습니다. 내용 일치 또는 관리자 정책이 조건입니다.
4. 내용 비교는 비동기입니다. 감지 후 화면 전환이며 붙여넣기/업로드 사전 방지나 이미 전달된 자료 회수를 보장하지 않습니다.
5. 관리자 정책은 Agent의 /blocklist를 사용합니다. Agent 연결 실패 시 마지막 정책을 사용합니다.
6. 확장의 tabs/webNavigation/alarms 권한은 안내 화면 전환과 정책 확인에 사용합니다.
7. 사용자/전체 STOP의 hosts 해제와 별개로 확장에 마지막 차단 정책이 남을 수 있습니다.
   중앙 정책 해제 후 Agent를 켜서 동기화하거나 확장을 꺼야 안내 전환도 중지됩니다.
8. 텍스트·파일 내용 비교 범위와 30분/50MiB 제한은 기존 버전과 동일합니다.

3.6.3 WATCH 표시 수정
실제 WATCH 판정이 발생하면 모든 규칙 경로에서 사건 목록에 노란 WATCH 기록을 저장합니다.
반복 WATCH는 같은 사용자 기록을 갱신하여 목록 중복을 줄입니다.
HIGH로 올라가도 이전 WATCH 사건은 판정 이력으로 남습니다. 현재 상태와 과거 사건은 다릅니다.
이미 HIGH인 사용자를 WATCH로 강제로 낮추거나 없었던 과거 사건을 생성하지 않습니다.
기존 확장이 3.6.2이면 이번 수정 때문에 재등록할 필요는 없습니다.
실행 중인 구버전 대시보드를 종료하고 이 폴더의 ADMIN_START 또는 start-all로 실행하세요.

3.6.4 시작 시 예시 로그 혼입 수정
대시보드 시작 시 예시 이벤트/예시 사건을 자동 입력하지 않습니다.
예시 로그가 실제 User를 HIGH로 만들던 문제를 수정했습니다.
이 ZIP에는 기존 테스트 DB를 포함하지 않습니다. 반드시 새 폴더에 압축을 풀어 실행하세요.
기존 폴더에 덮어쓰면 기존 gigang.db의 HIGH 상태가 남습니다.
현재 사용 중인 DB나 서버 기록을 삭제하지 않았습니다.
중앙 서버의 실제 과거 HIGH 기록이 다시 수집되면 HIGH가 될 수 있습니다.
확장은 기존 3.6.2를 그대로 써도 됩니다. 대시보드 수집 ON을 확인하세요.
