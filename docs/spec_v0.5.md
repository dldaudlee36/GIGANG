# 🛡️ [프로젝트 기획서 v0.5] 제로 트러스트 & 지능형 보안 이벤트 상관분석 시스템

## 📌 1. 프로젝트 개요
본 프로젝트는 **모바일/원격 접속 환경에서의 제로 트러스트(Zero Trust) 실시간 검증 및 감청 방어**부터 **기업 내부망 침해사고의 다단계 상관분석(Correlation)**까지 아우르는 AI 기반 차세대 통합 보안관제 및 자동대응(SOAR) 시스템입니다.

---

## 🎨 2. 주요 시나리오 2가지

### 📱 시나리오 A: "공공 Wi-Fi에서 내 개인정보가 샌다?" — 제로 트러스트 모바일 안전 관제
* **실생활 문제**: 카페, 지하철, 공항 등 오픈 Wi-Fi 환경에서 악의적인 가짜 AP(Rogue AP)나 패킷 감청(ARP Spoofing, SSL Stripping)에 노출된 채 금융/업무 앱에 접속하는 위험이 큽니다.
* **시스템 동작 흐름**:
  1. **상태 진단 (Zero Trust PDP)**: 사용자가 외부 Wi-Fi 접속 상태에서 회사/금융 서비스에 접근을 시도합니다.
  2. **AI 이상탐지 (MitM Detection)**: 
     - 사용자의 위치, 네트워크 RTT/지연 시간, DNS 변조 여부, SSL 인증서 발급자 이상 유무를 AI가 실시간 진단하여 **"가짜 AP(Man-in-the-Middle) 공격 의심 (위험도 CRITICAL)"**으로 분류합니다.
  3. **SOAR 대응**: 
     - 해당 앱의 중요 API 요청을 즉시 차단하고, 자동으로 VPN 터널링을 강제 전환하거나 세션을 만료시킵니다.
  4. **요약 알림 (User Briefing)**: 
     - *"⚠️ 현재 접속한 Wi-Fi는 보안이 취약합니다. 안전한 VPN으로 자동 전환했습니다."*라는 메시지와 원인 분석 보고서를 제공합니다.

```mermaid
flowchart LR
    A["공공 Wi-Fi 접속"] --> B["상태 진단 (위치·DNS·SSL)"]
    B --> C["🤖 AI MitM 탐지"]
    C --> D["⚡ SOAR: API 차단 & VPN 전환"]
    D --> E["사용자 요약 알림 발송"]
```

### 🏢 시나리오 B: 기업 내부 다단계 횡적이동 및 DB 대량 유출 상관분석
* **문제**: 개별 시스템(인증, 방화벽, DB)의 로그만 보면 정상적인 행위처럼 보이지만, 이를 시간과 네트워크 경로로 연결하면 공격 흐름이 드러납니다.
* **시스템 동작 흐름**:
  1. 외부 IP SSH 무차별 대입 후 로그인 성공 (Initial Access)
  2. 웹서버에서 내부 점프서버로 접근 (Lateral Movement)
  3. DB 포트(3306) 접근 후 고객 개인정보 테이블 50,000건 대량 조회
  4. 외부 미인가 IP로 대용량 데이터 전송 시도 (Exfiltration)
  5. **상관분석 엔진**: 시간(10분 이내), 계정(admin), IP 체인, Kill-Chain 순서를 종합하여 점수(12.0/12.0) 산출 및 Incident 생성.
  6. **AI 초동 조치**: MITRE ATT&CK 맵핑 및 1-Click 방화벽 차단 스크립트 실행.

```mermaid
flowchart LR
    A["외부 IP 로그인 실패/성공"] --> B["내부 점프서버 횡적이동"]
    B --> C["DB 대량 조회"]
    C --> D["외부 비정상 송신"]
    D --> E["상관분석 Incident 생성"]
```

## 🛠️ 4. 기술 스택

| 영역 | 기술 | 선정 이유 |
| :--- | :--- | :--- |
| **분석 & 수집** | Python 3.10+ | 네트워크 메타데이터 분석 및 로그 파싱이 용이함 |

| **로컬 환경** | Docker Compose / SQLite | 팀원 간 동일한 테스트 환경 구축 및 이력 저장 |

## 💬 6. 면접 예상 질문 및 모범 답변

> **Q. 이 프로젝트를 왜 만들었으며, 기존 SIEM과의 차별점은 무엇인가요?**  
> *"기존 관제 시스템은 사내 망 안의 서버 로그 분석에 치중되어 있어, 원격 근무나 모바일 환경(카페 공공 Wi-Fi 등)에서 발생하는 제로 트러스트 위협을 즉시 방어하기 어려웠습니다. 저희 프로젝트는 **‘외부 엔드포인트의 제로 트러스트 실시간 검증(가짜 AP 감청 방어 및 자동 VPN 전환)’**과 **‘내부 인프라의 다단계 침해 상관분석’**을 하나의 파이프라인으로 엮어, 실생활 접속 보안부터 기업 핵심 DB 보호까지 전방위로 방어하고 AI로 초동 조치를 자동화(SOAR)하도록 설계했습니다."*
